# Офлайн-колода Anki для китайского языка

Генератор колод Anki для изучения китайского с русским переводом. У каждого слова две карточки:

- **Русский → китайский**: написать иероглифы от руки (мышью, планшетом, пальцем или стилусом) и ввести pinyin;
- **Китайский → русский**: ввести перевод и pinyin.

Рукописный ввод проверяется через [Hanzi Writer](https://hanziwriter.org/) с учётом порядка и направления черт. Карточки работают полностью офлайн в Anki Desktop и AnkiDroid. Кнопка «Проверить» только показывает результат: оценку (Again/Hard/Good/Easy) вы выбираете сами, расписание Anki не меняется.

Слова и ключи взяты из уроков 1–6 учебника и собраны в одну колоду:

```text
Китайский для русскоязычных
├── Слова::Урок 1…6
└── Ключи::Урок 1…6
```

## Готовые колоды

Собирать проект не обязательно: готовые пакеты лежат в папке [`decks/`](decks/). Скачайте нужный файл (кнопка «Download raw file» на странице файла) и импортируйте его в Anki.

| Файл | Что внутри |
|---|---|
| `chinese-ru.apkg` | все уроки: слова и ключи |
| `chinese-ru-lesson-NN.apkg` | слова одного урока |
| `chinese-ru-radicals-lesson-NN.apkg` | ключи одного урока |

Пакеты можно импортировать в любом сочетании и повторно: уже импортированные карточки обновятся, а не задвоятся.

## Сборка

Нужны Git, Python 3.10+, Node.js с npm и Anki.

```bash
git clone https://github.com/turnbluee/chinese-ru-anki.git
cd chinese-ru-anki
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
make install
make test
make build
```

Без `make` (например, в Windows) выполните команды из `Makefile` вручную:

```bash
python -m pip install -r requirements.txt
npm install
python -m pytest
python src/build_lessons.py --input data/cards.tsv --radicals data/radicals.tsv --output-dir dist
```

Результат — `dist/chinese-ru.apkg`. Дополнительно создаются `chinese-ru-lesson-NN.apkg` и `chinese-ru-radicals-lesson-NN.apkg` для импорта отдельных уроков.

## Импорт

Импортируйте `dist/chinese-ru.apkg` в Anki Desktop (File → Import) или AnkiDroid, затем синхронизируйтесь через AnkiWeb. Прогресс у компьютера и телефона общий.

Повторный импорт после обновления данных обновляет существующие карточки, а не создаёт дубли. Anki сопоставляет колоды по имени, поэтому не переименовывайте колоды уроков, иначе при следующем импорте появятся новые пустые колоды с исходными именами.

## Свои слова

Слова лежат в `data/cards.tsv`, ключи — в `data/radicals.tsv`. Это TSV в UTF-8 с колонками, разделёнными табуляцией:

```text
uid	hanzi	pinyin	russian	russian_accepted	notes
ni-001	你	ni3	ты	ты	Урок 1; местоимение
```

- `uid` — уникальный постоянный идентификатор. Не меняйте его после импорта: по нему Anki узнаёт карточку;
- `hanzi` — иероглифы ответа; латиница, цифры и знаки препинания не требуют рукописного ввода;
- `pinyin` — см. правила ниже;
- `russian` — задание на карточке «русский → китайский»;
- `russian_accepted` — все допустимые переводы через `|`; регистр, лишние пробелы и `ё`/`е` не учитываются;
- `notes` — начинается с `Урок N;`, по этой пометке запись попадает в колоду урока.

Для нового урока добавьте его в `LESSONS` и `RADICAL_LESSONS` в `src/build_lessons.py` с новым постоянным ID колоды и обновите ожидаемые количества в `tests/test_build.py`.

### Pinyin

Только цифры тонов, строчными буквами, без пробелов:

```text
ni3  zhi1dao4  xue2sheng0  ke3'ai4  lv3xing2  zhe4er0
```

- нейтральный тон — `0` (не `5` и не пропуск);
- `ü` записывается как `v`; при ответе можно вводить и `ü`, и `v`;
- эризация хранится отдельным слогом: 这儿 → `zhe4er0`, 玩儿 → `wan2er0`.

Сборка проверяет данные и при ошибке называет строку и поле.

## Решение проблем

- **В AnkiDroid не появляется клавиатура в полях ответа**: включите «Настройки → Расширенные → Type answer into the card» и проверьте, что «Disable typing in answer» выключено.
- **В AnkiDroid не реагирует «Проверить»**: обновите AnkiDroid до 2.24 или новее.
- **Квадраты для письма есть, но иероглиф не пишется**: в коллекции нет данных для этих иероглифов. Пересоберите колоду (`make build`), импортируйте `chinese-ru.apkg` и синхронизируйте медиафайлы на всех устройствах. Медиафайлы колоды получают в имени хеш содержимого (`_hanzi-data-<хеш>.js`), поэтому Anki не может оставить устаревшую копию.
- **Штрих прокручивает экран**: начинайте линию внутри квадрата для письма.
- **Слишком строгая или мягкая проверка почерка**: измените `HANDWRITING_LENIENCY` в `web/card.js` (по умолчанию `1.5`; больше — мягче) и пересоберите колоду.

## Устройство проекта

- `data/` — слова и ключи;
- `src/` — проверка данных (`validators.py`, `pinyin.py`) и сборка (`build_assets.py`, `build_deck.py`, `build_lessons.py`);
- `templates/`, `web/card.js` — шаблоны и логика карточек;
- `tests/` — тесты на Python и JavaScript (`make test`, `npm test`).

Hanzi Writer и данные иероглифов (`hanzi-writer@3.7.3`, `hanzi-writer-data@2.0.1`) ставятся через npm и встраиваются в колоду. В пакет попадают данные только тех иероглифов, которые в ней используются.
